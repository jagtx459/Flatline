Backup & restore

Configuration (JSON)

Export endpoints, Flatline groups, action targets, action groups, and notification channels to a JSON file. Credentials are included but stay encrypted. Importing to another instance works only if it uses the same encryption key. Importing replaces all existing configuration.

Database

Download a full snapshot of the SQLite database (configuration and history), or restore one. Restoring replaces the entire database; stored credentials work only if this instance uses the same encryption key as the backup. It is STRONGLY recommended to have access to your current encryption key or generate a new one prior to performing a backup->restore procedure.

This will reset all endpoints, groups, actions, channels, history, removes the site password, and clears settings. Only the encryption key is kept.

Wake-on-LAN relays

Add relay

▸

A magic packet is a broadcast, and broadcasts do not cross routers. Flatline can only wake a machine on a network it is itself attached to. A relay is a machine that already sits on the target's network — a NAS, a hypervisor, a Pi — which Flatline signs in to and asks to send the packet locally. Set one up per network you need to wake into, then pick it on the action target's Restore step. Credentials are encrypted at rest and never sent back to the browser; leave a credential blank when editing to keep the stored value.

Needs WinRM enabled on the host (Enable-PSRemoting -Force); the default port is 5985.

Installing a wake tool on the relay

Windows relays need nothing installed — the default command uses PowerShell, which is always present. On Linux the tool is not installed by default, and the package name and command differ by distribution:

# Debian / Ubuntu
sudo apt install wakeonlan          ->  wakeonlan {mac}

# Fedora
sudo dnf install wol                ->  wol {mac}

# RHEL / Rocky / AlmaLinux (wol comes from EPEL)
sudo dnf install epel-release
sudo dnf install wol                ->  wol {mac}

# Alpine
sudo apk add wakeonlan              ->  wakeonlan {mac}

Whichever you install, put the matching command in the field above. If you cannot install anything, this one-liner uses only core Perl, which is present on essentially every Linux (guaranteed on Debian/Ubuntu, where perl-base is an essential package):

perl -e 'use Socket; socket(S,PF_INET,SOCK_DGRAM,getprotobyname("udp"));
setsockopt(S,SOL_SOCKET,SO_BROADCAST,1);
$m = "{mac}"; $m =~ s/[:-]//g;
send(S, "\xff" x 6 . pack("H*",$m) x 16, 0, sockaddr_in(9, inet_aton("255.255.255.255")));'

Test the connection below before saving — that proves the login works. It does not send a packet, since that would actually power a machine on.
