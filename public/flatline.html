Add Flatline endpoint

An endpoint is one thing Flatline watches, on its own interval.

Endpoints always start ungrouped. Add them to a Flatline group in the form below to tie them to actions — nothing triggers until they are in one.

Add Flatline group

A Flatline group sets the failure condition for a set of endpoints. An endpoint can belong to more than one group.

Assign action groups to this group from the Actions page — those are what actually run when it triggers.
